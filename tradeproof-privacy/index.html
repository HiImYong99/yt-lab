개인정보 처리방침

시행일: 2026-08-27 · English

YT Lab(이하 "운영자")은 TradeProof 앱(이하 "서비스") 이용자의 개인정보를 아래와 같이 처리합니다.

1. 수집하는 정보

항목목적보관
이메일 주소계정 생성·로그인·이메일 인증탈퇴 시 삭제
닉네임리더보드·프로필 표시탈퇴 시 삭제
거래소 API 키(읽기 전용)잔고·입출금 조회 및 수익률 계산연동 해제 또는 탈퇴 시 즉시 삭제
잔고 스냅샷·보유 자산수익률·MDD 등 지표 계산, 랭킹 산정탈퇴 시 삭제

2. API 키의 처리

  • 거래소 API 키는 읽기 전용 권한만 등록할 수 있으며, 출금·주문 권한이 있는 키는 등록이 거부됩니다.
  • 키는 서버에서 AES-256-GCM으로 암호화되어 저장되며, 이용자 기기(클라이언트)에는 저장되지 않습니다.
  • 키는 잔고·입출금 이력 조회에만 사용됩니다.

3. 공개되는 정보

  • 닉네임, 수익률·MDD 등 백분율 지표, 정규화된 수익률 곡선(지수)만 다른 이용자에게 공개될 수 있습니다.
  • 잔고 금액·보유 자산 내역 등 절대 금액은 공개되지 않습니다.
  • 프로필 공개 범위는 앱 내 설정에서 변경할 수 있습니다.

4. 처리 위탁 및 제3자 제공

서비스는 Google Firebase(인증·데이터베이스·서버리스 함수, Google LLC)를 이용하여 데이터를 처리합니다. 이 외의 제3자에게 개인정보를 판매하거나 제공하지 않습니다.

5. 파기

앱 내 "계정 삭제" 시 이메일, 닉네임, API 키, 잔고 스냅샷, 지표 기록이 즉시 영구 삭제됩니다.

6. 이용자 권리

이용자는 언제든지 앱 내에서 연동 해제·계정 삭제를 할 수 있으며, 개인정보 관련 문의는 아래 연락처로 할 수 있습니다.

7. 면책

서비스의 모든 정보는 사실 전달 목적이며 투자 자문이 아닙니다. 투자 판단과 그 결과에 대한 책임은 이용자 본인에게 있습니다.
