Squeeze Play: Baseball Manager 2.0 · 야구감독 키우기

개인정보 처리방침

시행일: 2026년 11월 2일 (2.0.0)

한국어 · English

YT Lab(이하 "개발자")은 Squeeze Play: Baseball Manager 2.0 (야구감독 키우기)(이하 "앱")를 운영합니다. 회원가입이나 로그인은 없으며 이메일·전화번호·실명을 요구하지 않습니다. 무작위 기기·구단주 식별자로 서버 기능을 제공합니다.

2. 보관과 클라우드 저장

  • 게임 데이터는 기기에 저장되며, 네이티브 앱은 재설치 후 복원을 위해 저장 데이터 사본을 개발자 서버에 자동으로 올립니다. 복원 계정은 기기의 키체인 또는 키스토어에 저장된 무작위 식별자입니다.
  • 랭킹, 지갑, 저장 사본과 동의한 사용 분석 기록은 서버에서 처리·보관됩니다. 삭제를 원하면 아래 방법으로 요청하세요. 앱 삭제는 기기 데이터를 삭제하지만 서버 데이터 삭제 요청을 대신하지 않습니다.
  • 설정 > 구단주 이동에서 7일 동안 유효한 코드를 사용해 구단주를 이동할 수 있습니다.

3. 광고

  • 네이티브 앱은 Google AdMob 하단 배너와 첫 커리어 이후 6시즌마다 전면광고를 표시합니다. 이용자는 보상형 광고를 선택해 추가 굴림 10회를 받을 수 있습니다.
  • iOS에서는 앱 추적 투명성(ATT), 유럽경제지역(EEA)에서는 UMP 동의 양식이 적용됩니다. 자세한 내용은 Google 개인정보처리방침을 참고하세요.
  • 광고 제거 상품은 배너와 전면광고를 제거합니다. 선택형 보상 광고는 별도입니다.

4. 결제

  • Apple과 Google이 결제를 처리하며 미니앱에서는 토스가 처리합니다. 개발자는 카드 등 금융 정보를 받지 않습니다. 서버는 영수증을 검증해 골드·티켓을 지급합니다.
  • 상품은 광고 제거, 감독 유형 팩(투수 운용가·데이터 야구), 후원 팩(보관함 10→50 및 배지), 골드 팩, 굴림 티켓입니다. 티켓은 시작 능력치 다시 굴림에 쓰이는 유료 확률형 아이템이며 확률은 앱에 표시됩니다.

5. 제3자 처리

개발자는 이용자 정보를 판매하지 않습니다. 위 기능을 위해 Cloudflare가 서버 데이터를 처리하고, Apple·Google·토스가 결제 또는 광고를 처리합니다. 법령에 따른 요청이 있는 경우 정보가 제공될 수 있습니다.

6. 이용자의 권리와 삭제

  • 설정에 표시된 서버 ID를 contact@ytlab.site로 보내 서버 데이터 삭제를 요청할 수 있습니다. 앱을 삭제하면 기기 데이터가 삭제됩니다.
  • 랭킹 화면 맨 아래에서 랭킹 참여를 끌 수 있고, 설정에서 사용 분석을 끌 수 있습니다. 광고 식별자는 기기 설정에서 제한하거나 재설정할 수 있습니다.

7. 랭킹

은퇴한 커리어의 주간·월간·전체 기간 랭킹을 제공합니다. 감독 이름, 감독 유형, 구단, 아바타, 은퇴 나이, 통계, 칭호, 시즌 승패·순위·목표가 서버에 올라갑니다. 이름은 자동 생성되며 직접 입력한 이름은 별도 동의한 경우에만 전송됩니다. 랭킹 참여를 끄면 이후 기록은 전송되지 않습니다.

부적절한 이름을 걸러내는 차단 목록과 신고·차단 기능이 있으며, 신고 3건을 받은 기록은 숨겨집니다.

8. 사용 분석

첫 실행 시 동의한 경우에만 사용 이벤트와 무작위 설치 ID를 자체 서버로 보내 게임 개선에 사용합니다. 이름과 광고 식별자는 포함하지 않습니다. 설정에서 언제든 끌 수 있으며, 토스 미니앱에서는 사용 분석을 하지 않습니다.

9. 토스 미니앱

앱인토스 미니앱 '야구감독 키우기'의 광고와 결제는 토스가 처리합니다. 토스 로그인 익명 키는 지갑 연결에만 사용합니다. '3분 플레이하면 토스 포인트 2원' 프로모션의 포인트는 토스가 지급합니다.

10. 아동과 게임 내 명칭

앱은 아동을 대상으로 하지 않습니다. 게임의 리그·구단·선수·감독 이름은 모두 허구입니다.
