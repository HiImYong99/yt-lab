쿠파노트

개인정보 처리방침

시행일: 2026년 7월 29일

YT Lab(이하 "개발자")은 모바일 앱 쿠파노트(이하 "앱")를 운영합니다. 앱은 이용자가 본인의 쿠팡 파트너스 오픈 API 키를 입력하면 그 키로 본인의 제휴 실적을 조회해 요약과 알림을 제공하는 서비스입니다.

쿠파노트는 쿠팡 및 쿠팡 파트너스가 만든 공식 앱이 아닙니다. 쿠팡과 제휴·후원 관계가 없는 독립 앱이며, 쿠팡의 상표는 서비스를 설명하기 위해서만 사용합니다.

1. 수집하는 정보

항목수집 목적보관 위치

제휴 실적 데이터(클릭·주문·수수료·취소) 요약·추이 제공, 알림 발송 서버

광고 식별자 광고 게재 (Google AdMob) Google

앱은 회원가입을 요구하지 않습니다. 이름, 이메일, 전화번호, 생년월일, 위치정보, 연락처, 사진 등 별도의 개인정보를 수집하지 않습니다.

2. API 키의 취급

  • Secret Key는 암호화 저장소에 보관하며, 실적을 조회하는 순간에만 서버 내부에서 복호화합니다.
  • 앱과 이용자 단말에는 원문이 남지 않으며, 저장된 키를 다시 조회할 수 있는 경로를 두지 않았습니다.
  • 이 키의 권한은 실적 조회에 한정됩니다. 이 키로는 정산 계좌를 조회·변경할 수 없고, 출금할 수 없으며, 쿠팡 계정 정보에 접근하거나 주문을 생성할 수 없습니다.
  • 앱 [설정 → 저장된 API 키 지우기]에서 언제든 삭제할 수 있습니다. 삭제 시 키는 즉시 파기되고 실적 수집이 중단됩니다.

3. 제3자 제공 및 국외 이전

개발자는 이용자의 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 다만 서비스 제공을 위해 아래 처리위탁이 발생합니다. 이용자의 실적 데이터를 외부 인공지능 서비스로 보내지 않습니다.

수탁자위탁 내용이전 국가

4. 보유 및 파기

  • API 키: 이용자가 삭제할 때까지. 삭제 시 즉시 파기.
  • 실적 데이터: 계정 삭제 시 함께 삭제됩니다.
  • 이용자가 앱을 삭제하더라도 서버 데이터는 자동 삭제되지 않습니다. 완전한 삭제를 원하시면 앱 삭제 전에 [저장된 API 키 지우기]를 실행하시거나 아래 연락처로 요청해 주십시오.

5. 이용자의 권리

이용자는 언제든지 본인의 정보에 대한 열람·정정·삭제·처리정지를 요청할 수 있습니다. 앱 내 기능으로 즉시 삭제할 수 있으며, 그 외의 요청은 아래 연락처로 접수합니다.

6. 광고

무료 이용자에게는 Google AdMob 광고가 표시되며, 광고 식별자가 사용될 수 있습니다. 구독 시 광고가 제거됩니다. 광고 개인화 설정은 기기의 설정에서 변경할 수 있습니다. Google의 데이터 처리에 대해서는 Google 개인정보처리방침을 참고하십시오.

7. 아동의 개인정보

앱은 만 13세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 알면서 수집하지 않습니다.

8. 안전성 확보 조치

  • 모든 통신은 TLS로 암호화합니다.
  • API 키는 암호화 저장소에 보관하며, 서버의 조회 권한을 최소 범위로 제한했습니다.
  • 데이터베이스는 이용자별 접근 제어를 적용해 다른 이용자의 데이터를 조회할 수 없습니다.

9. 변경 고지

본 방침이 변경될 경우 앱 내 공지 또는 본 페이지를 통해 알립니다.
