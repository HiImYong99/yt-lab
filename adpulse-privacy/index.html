AdPulse

개인정보 처리방침

시행일: 2026년 7월 10일

한국어 · English

YT Lab(이하 "개발자")은 모바일 앱 AdPulse(이하 "앱")를 운영합니다. 앱은 이용자가 본인의 Google 계정으로 로그인해 본인의 AdMob·AdSense 광고 수익을 조회하는 대시보드입니다. 개발자는 자체 서버를 운영하지 않으며, 이용자의 수익 데이터와 인증 정보는 이용자 기기 밖으로 전송·저장되지 않습니다.

1. 처리하는 정보

항목시점목적·보관
Google 계정 기본 프로필(이름, 이메일, 프로필 사진)Google 로그인 시앱 내 계정 표시. 기기에만 보관
AdMob 보고서 데이터(예상 수익 등, 읽기 전용)이용자가 AdMob 연결에 동의한 경우대시보드 표시. 기기에만 캐시
AdSense 보고서 데이터(예상 수익 등, 읽기 전용)이용자가 AdSense 연결에 동의한 경우대시보드 표시. 기기에만 캐시
앱이 Google API로부터 받은 정보는 기기 내 대시보드 표시라는 단일 목적에만 사용됩니다. 수익 데이터를 제3자에게 판매·공유·이전하지 않으며, 광고 목적으로 사용하지 않고, 사람이 열람하지 않습니다.

2. Google API 접근(제한적 사용 고지)

앱은 Google 로그인 후 이용자가 명시적으로 동의한 경우에만 아래의 읽기 전용 권한을 요청합니다.

  • admob.readonly — AdMob 보고서 조회
  • adsense.readonly — AdSense 보고서 조회

AdPulse가 Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 포함하여 해당 정책을 준수합니다.

3. 광고 없음

앱에는 광고가 없으며, 광고 SDK·추적 기술을 사용하지 않습니다. 광고 식별자(IDFA/AAID)를 수집하지 않습니다.

4. 데이터 보관·삭제

  • 수익 데이터 캐시와 로그인 상태는 이용자 기기에만 저장되며, 앱에서 로그아웃하거나 앱을 삭제하면 제거됩니다.
  • 앱의 Google 계정 접근 권한은 Google 계정 > 보안 > 제3자 액세스에서 언제든지 철회할 수 있습니다.

5. 제3자 서비스

  • Google 로그인(Google Identity) — 계정 인증
  • Google AdMob API·AdSense Management API — 수익 데이터 조회(읽기 전용)

6. 아동의 개인정보

앱은 광고 게시자(개발자·퍼블리셔)를 대상으로 하며 만 13세 미만(대한민국 만 14세 미만) 아동을 대상으로 하지 않습니다.

8. 고지 의무

본 방침이 변경되는 경우 이 페이지를 통해 공지하며, 중요한 변경은 앱 내에서 별도로 알립니다.

AdPulse는 독립 앱으로 Google과 관련이 없습니다. AdMob과 AdSense는 Google LLC의 상표입니다.
